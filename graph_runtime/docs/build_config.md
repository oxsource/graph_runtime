# Build Configuration Guide

## 1. Build System Overview

Graph Runtime uses **Bazel 6.5.0** (`.bazelversion`) as its build system. The build
configuration is organized across three layered files to separate project-wide
defaults from machine-local platform detection.

### 1.1 Bazel Entry Points

| Command | Purpose |
|---------|---------|
| `bazel build //...` | Build everything for the host platform |
| `bazel test //...` | Run all test suites |
| `bazel build //src/framework/public:runtime_shared` | Build the public shared library only |

### 1.2 Platform Targets

Graph Runtime defines four platform targets (see `platforms/BUILD`):

| Config alias | Platform target | Use case |
|-------------|----------------|----------|
| `--config=macos_arm64` | `//platforms:macos_arm64` | macOS Apple Silicon |
| `--config=macos_x86_64` | `//platforms:macos_x86_64` | macOS Intel |
| `--config=linux_x86_64` | `//platforms:linux_x86_64` | Linux x86-64 |
| `--config=linux_aarch64` | `//platforms:linux_aarch64` | Linux AArch64 |

The host platform is auto-detected by `tools/platform_setup.sh`, which writes
the corresponding `--config=` flag into `.user.bazelrc`.

## 2. Configuration File Layering

```
.bazelrc                 # Project-wide, committed (shared config, aliases,
                          #   try-import directives)
    try-import .configure.bazelrc   # Auto-generated by CI/setup (optional)
    try-import .user.bazelrc        # Machine-local, generated by platform_setup.sh
```

### 2.1 `.bazelrc` (committed)

Contains project-wide settings:
- C++ standard (`--cxxopt=-std=c++17`)
- Platform config aliases (`--config=macos_arm64`, etc.)
- `--enable_platform_specific_config` for Bazel host-platform auto-detection
- `try-import` for local overrides

### 2.2 `.configure.bazelrc` (optional, git-ignored)

Intended for auto-generated settings produced by CI scripts or one-time
setup tools. Currently unused — reserved for future automation.

### 2.3 `.user.bazelrc` (machine-local, git-ignored)

Written by `tools/platform_setup.sh` after detecting the host platform.
Contains a single `build --config=<platform>` line that sets the default
platform for all `bazel build //...` invocations.

---

## 3. Platform Auto-Detection Script

### 3.1 `tools/platform_setup.sh`

Detects the host operating system and CPU architecture, then writes
`.user.bazelrc` with the correct `--config` flag. Run once after cloning.

### 3.2 Usage

```bash
./tools/platform_setup.sh          # verbose mode (default)
./tools/platform_setup.sh --quiet  # silent; errors only
```

### 3.3 Detection Logic

| Host | Architecture | Config written |
|------|-------------|----------------|
| macOS | arm64 | `build --config=macos_arm64` |
| macOS | x86_64 | `build --config=macos_x86_64` |
| Linux | x86_64 | `build --config=linux_x86_64` |
| Linux | aarch64/arm64 | `build --config=linux_aarch64` |

### 3.4 Output Example

```
  Platform:    macOS arm64 (Apple Silicon)
  Config:      bazel build //... --config=macos_arm64

Wrote /path/to/graph_runtime/.user.bazelrc
```

## 4. Build Command Quick Reference

| Scenario | Command |
|----------|---------|
| Build everything (host) | `bazel build //...` |
| Run all tests | `bazel test //...` |
| Build public shared lib | `bazel build //src/framework/public:runtime_shared` |
| Build for macOS arm64 | `bazel build //... --config=macos_arm64` |
| Build for macOS x86_64 | `bazel build //... --config=macos_x86_64` |
| Build for Linux x86_64 | `bazel build //... --config=linux_x86_64` |
| Build for Linux AArch64 | `bazel build //... --config=linux_aarch64` |
| Regenerate `.user.bazelrc` | `./tools/platform_setup.sh` |

---

## 5. Adding a New Platform

1. Add `config_setting_and_platform` entry in `platforms/BUILD` with the
   appropriate `@platforms//os:*` and `@platforms//cpu:*` constraint values.
2. Add a `build:<config_alias> --platforms=//platforms:<target>` line in `.bazelrc`.
3. Add detection logic in `tools/platform_setup.sh`.
4. Update this document.
